# Установка на хостинг Beget (wb.linkoz.ru)

Займёт примерно 15 минут. Сервис будет работать на домене **https://wb.linkoz.ru**.

> На 25.10.2026 сайт `wb.linkoz.ru` на Beget уже создан, HTTPS работает, в `public_html` лежит заглушка Beget.
> Шаг 1 можно пропустить, если для сайта уже выбран PHP 8.1+.

## Быстрая установка (кратко)

```bash
# 1) по SSH на Beget
cd ~/wb.linkoz.ru
mv public_html public_html.bak            # убираем заглушку Beget
git clone -b beget-ready https://github.com/mahmadali91/lentazakazWB.git public_html
```
2) Откройте https://wb.linkoz.ru/install. Имя базы и пользователя `mahmadgv_wblenta` уже подставлены, введите пароль БД, email и пароль администратора.
3) Добавьте задание CRON на каждую минуту:
   `/usr/local/bin/php8.2 /home/m/mahmadgv/wb.linkoz.ru/public_html/cron/sync.php`
   (точный путь и версию PHP установщик покажет в конце — сверьтесь с ними).

Подробно — ниже.

## 1. Сайт и PHP

1. Панель Beget → **«Сайты»**: сайт `wb.linkoz.ru` с папкой `~/wb.linkoz.ru/public_html` (уже создан). Если папка у сайта называется иначе, подставляйте её путь в командах ниже.
2. В настройках сайта выберите **PHP 8.2** или 8.3 (нужен как минимум 8.1).
3. Раздел **«SSL-сертификаты»** → выпустите бесплатный сертификат Let's Encrypt для домена.

## 2. База данных

Панель → **«MySQL»**: база **`mahmadgv_wblenta`** (уже создана). На Beget имя пользователя совпадает с именем базы. Пароль запишите.

## 3. Загрузка кода

### Вариант А: через SSH и git (рекомендуется, так проще обновлять)

Включите SSH: панель → **«SSH»**. Затем подключитесь и выполните:

```bash
cd ~/wb.linkoz.ru
mv public_html public_html.bak   # в папке только заглушка Beget, её можно удалить позже
git clone -b beget-ready https://github.com/mahmadali91/lentazakazWB.git public_html
```

Весь репозиторий окажется в `public_html`. Корневой `.htaccess` сам направляет запросы в `public/` и закрывает доступ к `src/`, `config/`, `storage/`, `cron/`, `database/`, `tools/` и `.git/`.

> Альтернатива для опытных: клонируйте в `~/lentazakaz` и сделайте симлинк
> `ln -s ~/lentazakaz/public ~/wb.linkoz.ru/public_html`.

### Вариант Б: через файловый менеджер

На GitHub нажмите **Code → Download ZIP** (ветка `beget-ready`), распакуйте и загрузите содержимое в `public_html` через файловый менеджер Beget. Скрытые файлы `.htaccess` тоже должны попасть на сервер.

## 4. Веб-установщик

Откройте `https://wb.linkoz.ru/`. Сайт сам перенаправит на `/install`:

- проверит версию PHP и расширения (на Beget всё есть по умолчанию);
- попросит данные MySQL (хост `localhost`), email и пароль администратора;
- создаст таблицы, учётную запись администратора и файл `config/config.php` с уникальным ключом шифрования.

⚠️ **Сохраните копию `config/config.php`.** В нём лежит `app.key`: без этого ключа сохранённые токены WB не расшифровать.

## 5. Задание CRON (обязательно)

Панель → **«CRON»** → «Добавить задание»:

- Периодичность: **каждую минуту** (`* * * * *`)
- Команда:
  ```
  /usr/local/bin/php8.2 /home/m/mahmadgv/wb.linkoz.ru/public_html/cron/sync.php
  ```
  Точную команду с правильным путём показывает установщик в конце и админ-панель (`/admin`). Номер версии PHP в команде должен совпадать с выбранной для сайта.

Через минуту в админ-панели должна появиться надпись «CRON работает».

## 6. Telegram-бот (по желанию)

1. В Telegram откройте @BotFather → `/newbot` → получите токен.
2. В `config/config.php` заполните:
   ```php
   'telegram' => ['bot_token' => '123456:ABC…', 'bot_username' => 'имя_бота_без_@'],
   ```
3. Пользователи подключают уведомления в разделе «Настройки»: бот привязывает аккаунт сам, вебхук настраивать не нужно.

## 7. Оплата через ЮKassa (по желанию)

1. Зарегистрируйтесь на yookassa.ru и подключите магазин. Понадобятся ИП или самозанятость, а также оферта на сайте.
2. В `config/config.php`:
   ```php
   'yookassa' => ['shop_id' => '123456', 'secret_key' => 'live_…', 'send_receipt' => false, 'vat_code' => 1],
   ```
   `send_receipt => true` включайте, если подключены чеки ЮKassa (54-ФЗ).
3. Кабинет ЮKassa → Интеграция → **HTTP-уведомления**: URL `https://wb.linkoz.ru/webhook/yookassa`, события `payment.succeeded` и `payment.canceled`.

Пока ЮKassa не настроена, тарифы можно выдавать вручную: админ-панель → «Пользователи».

## 8. Обязательно поправьте

- `src/views/home/legal.php` — замените шаблоны оферты и политики конфиденциальности на свои тексты с реквизитами;
- `config/plans.php` — цены и лимиты тарифов;
- `config/config.php` → `app.name`, `app.support_email`, `app.trial_days`.

## Обновление

```bash
cd ~/wb.linkoz.ru/public_html && git pull
```

`config/config.php` и `storage/` git не затрагивает. Таблицы базы данных обновляются автоматически при первом открытии сайта после обновления.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Ошибка 500 сразу после загрузки | Версия PHP ниже 8.1. Выберите 8.2 в настройках сайта |
| Страница «Сервис уже установлен» | Нормально: установщик блокируется после установки. Для переустановки удалите `config/config.php` |
| Заказы не появляются | Админ-панель → статус CRON и «Журнал синхронизации» |
| «WB временно ограничил запросы» | У пользователя «Базовый» токен (лимит 1 запрос в 3 часа). Нужен «Персональный» |
| «У токена нет доступа» | Создайте токен с категориями Аналитика, Статистика, Маркетплейс, Контент (для раздела «Финансы» — ещё Финансы и Продвижение) |
| Логи | `storage/logs/*.log` (через файловый менеджер) |
