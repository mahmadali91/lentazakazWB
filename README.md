# Лента заказов WB

SaaS-сервис для продавцов Wildberries: все заказы магазина в одной живой ленте. Поддерживаются все схемы работы (FBO, FBS, DBS, DBW, самовывоз, B2B), тарифы с оплатой через ЮKassa, уведомления в Telegram и выгрузка в Excel.

Боевой адрес: **https://wb.linkoz.ru**. Работает на обычном виртуальном хостинге (**Beget**): PHP 8.1+, MySQL и cron. Composer, Node.js и сборка не нужны.

👉 **Установка на Beget — [docs/INSTALL_BEGET.md](docs/INSTALL_BEGET.md)**
📚 **Как устроены API WB, которые мы используем — [docs/WB_API.md](docs/WB_API.md)**

## Возможности

- **Живая лента заказов**: новые заказы, выкупы, отмены и возвраты появляются в течение 5 минут без перезагрузки страницы. Новый заказ сопровождается звуком и браузерным уведомлением.
- **Все схемы**: FBO (склад WB), FBS, DBS, DBW, самовывоз (Click & Collect). Схема определяется автоматически.
- **Сводка**: заказы и сумма, выкупы, отмены, возвраты, средний чек, график по часам и дням, топ товаров.
- **Фильтры**: период (сегодня, вчера, 7 и 30 дней, свой), статус, схема, магазин, поиск по артикулу, WB ID, бренду и городу.
- **Несколько магазинов** в одном аккаунте, общая лента или по одному.
- **Telegram-бот**: уведомления о новых заказах, выкупах, отменах и возвратах.
- **Тарифы** (`config/plans.php`): лимиты магазинов, глубины истории, частоты обновления, Telegram и Excel. Пробный период 7 дней.
- **Оплата через ЮKassa**: карты и СБП, скидки за 3, 6 и 12 месяцев, вебхук с перепроверкой платежа, чеки по 54-ФЗ (опционально).
- **Себестоимость и прибыль**: себестоимость и комиссия по каждому товару (вручную или загрузкой CSV из Excel), налог, логистика и прочие расходы. Прибыль (оценка) показывается в каждом заказе и в сводке.
- **Финансы — чистая прибыль по отчётам WB** (как таблица «9.5»): еженедельные отчёты реализации, платное хранение и расходы на рекламу загружаются из WB автоматически. Вкладки: Сводка (дашборд), ОПИУ по неделям/месяцам, прибыль по товарам с ABC, ABC-анализ, детализация по заказам (Srid), отчёты WB со сверкой «Итого к оплате», себестоимость, хранение на SKU, реклама на SKU, прочие расходы, учёт самовыкупов, калькулятор участия в акции. Если у токена нет категории «Финансы», детализацию можно загрузить файлом .xlsx из кабинета WB.
- **API и подключение к Claude**: ключ доступа (только чтение) → MCP-сервер `/mcp/<ключ>` для коннектора claude.ai / Claude Code и REST `/api/v1/…`. Claude сам смотрит заказы, прибыль и состояние синхронизации. Подробно — `docs/API.md`.
- **Сотрудники**: владелец кабинета выдаёт сотрудникам доступ по логину и паролю. Сотрудник видит ленту и товары, но не может менять магазины, тариф и себестоимость.
- **Настройки сервиса** (админка): телефон и email поддержки, Telegram-бот (токен хранится в БД зашифрованным, проверяется через getMe). Телефон клиента обязателен при регистрации и в профиле.
- **Админ-панель**: клиенты со сроками доступа (фильтры «оплачен», «пробный», «истекает», «истёк»), продление в один клик, создание клиента с логином и паролем, смена пароля, заметки, вход в кабинет клиента, блокировка, платежи, напоминания клиентам за 3 дня до окончания срока, состояние cron, журнал синхронизации и ошибки магазинов.
- **Безопасность**: токены WB зашифрованы (AES-256-GCM), CSRF-защита, защита от перебора паролей, изоляция данных пользователей, служебные папки закрыты от веба.
- Светлая и тёмная темы, адаптивная вёрстка под телефон.

## Откуда берутся данные

| Источник WB | Категория токена | Что даёт | Частота |
|---|---|---|---|
| `POST /api/analytics/v1/order-feed` — «Лента заказов» | Аналитика | Все заказы всех схем в реальном времени, статусы выкуп/отмена/возврат | раз в 5 минут (лимит WB — 1 запрос/мин) |
| `GET /api/v3/orders/new`, `/dbs/…`, `/dbw/…`, `/click-collect/…` | Маркетплейс | Новые сборочные задания: точная схема, артикул, № задания | раз в 5 минут |
| `GET /api/v1/supplier/orders` | Статистика | Бренд, предмет, категория, реальный склад WB, цена для покупателя, СПП | раз в 30 минут |
| `POST /content/v2/get/cards/list` | Контент | Названия и фото товаров | раз в 6 часов |
| `POST /api/finance/v1/sales-reports/list` и `/detailed/{reportId}` | Финансы | Еженедельные отчёты реализации и их детализация — основа раздела «Финансы» | список — раз в 6 часов, детализация — 1 отчёт в минуту |
| `GET /api/v1/paid_storage` (задание → статус → скачивание) | Аналитика | Платное хранение по дням и товарам | раз в сутки, история — по 8 дней в минуту |
| `GET /adv/v1/upd`, `GET /api/advert/v2/adverts` | Продвижение | Списания за рекламу и товары кампаний | раз в 6 часов |

Нужна хотя бы одна категория из «Аналитики» и «Статистики». Остальные категории необязательны: они обогащают ленту и включают раздел «Финансы». Отчёты реализации WB отдаёт только по токену типа «Персональный» или «Сервисный».

## Структура

```
public/            ← веб-корень (index.php, assets)
src/Core           ← роутер, БД, авторизация, шифрование, шаблоны
src/Wb             ← клиент WB API
src/Services       ← синхронизация, заказы, тарифы, Telegram, ЮKassa, cron
src/Controllers    ← страницы и JSON API
src/views          ← шаблоны (PHP)
config/            ← config.php (создаёт установщик), plans.php (тарифы)
cron/sync.php      ← фоновая синхронизация (cron каждую минуту; к WB — по расписанию тарифа, раз в 5 минут)
database/schema.sql
tools/mock-wb.php  ← мок WB API и ЮKassa для локальной разработки
.htaccess          ← позволяет положить весь репозиторий прямо в public_html
```

## Локальный запуск (для разработки)

```bash
# 1. MySQL: создайте базу и пользователя
# 2. Мок WB API (по порту на сервис)
for p in 8090 8091 8092 8093 8094; do php -S 127.0.0.1:$p tools/mock-wb.php & done
# 3. Сайт
php -S 127.0.0.1:8080 -t public public/index.php
# 4. Откройте http://127.0.0.1:8080 и пройдите установку
# 5. В config/config.php направьте wb.hosts на мок:
#    common 8090, analytics 8091, statistics 8092, marketplace 8093, content 8094
#    Токен для мока — любая строка, начинающаяся с "test"
# 6. Синхронизация вручную:
php cron/sync.php -v
```

Сервис не является официальным продуктом Wildberries.
